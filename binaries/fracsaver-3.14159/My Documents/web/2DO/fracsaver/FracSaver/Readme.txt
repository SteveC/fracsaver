This is the FracSaver readme!

To run FracSaver version 3.141592 you need:

	Fractal Saver.scr - The saver
	FracSaver.ini     - INI file
	MSVBVM50.DLL      - Visual Basic Runtime
	TABCTL32.OCX      - Tab control for the settings window

Put the latter two in your windows\system directory and the first two in your windows 
directory. A standard settings file is given and can be re-generated by deleting your
old on and run the settings... window from display properties/screen savers in order 
to create a standard INI file. From then on have fun!

Note: This version supports the old setup files so you don't need to copy that over.
