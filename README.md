# FracSaver

Historical FracSaver project archive.

This repository preserves the old FracSaver source, Windows binaries, original download archives, and a copy of the old website page that linked to them. The files were copied into this repository without deleting or moving the originals.

## Layout

- `source/visual-basic-v5-fracsaver-5.0op/` - Extracted Visual Basic source from `fracsrc.zip`. The project metadata identifies this as `FracSaverOP version 5.0op`, built with VB5.
- `binaries/fracsaver-5.0a-self-extracting/` - Standalone Windows executable copied from `fracsaver.exe`. The archived HTML page labels this download as `FracSaver 5.0a`.
- `binaries/fracsaver-3.14159/` - Extracted legacy `FracSaver 3.14159` screen saver bundle from `frac314.zip`.
- `archives/` - Original ZIP archives preserved as received.
- `web/public_html_old/fractal/` - Historical HTML page copied for context.

## Notes

The old HTML page also references `fracop.exe` for FracSaver 5.0op, but that file was not included in the source paths used to build this repository.

The next step is to build a modern version while keeping this archive intact.
