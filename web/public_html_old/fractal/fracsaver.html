FracSaver


FracSaver includes 45 different configurable modules, each module a different fractal or example of ALife or dynamical system. When running FracSaver randomly displays the modules you have selected, in the setup window it is possible to preview all but one of the modules with standard settings enabled in 5.0a.

There are now two versions of FracSaver publically available. The first is 5.0a and includes a preview window in the config box and is compiled in VB6. The second, 5.0op is up to 70% faster than 5.0a as it does not have the preview window and is compiled in VB5.

FracSaver 5.0op is recommended for most users. 5.0a however is still available for fun.

The downloads are self extracting executables. The contain all the files neccesary to run. FracSaver requires Windows 95, 98 or NT to run.

FracSaver is a bit ugly, visually as well as the code. I have been meaning for some time to update it. I have made a little progress. Feel freee to bug me to work harder.
